# AI_Virtual_Assistance

This project is an AI-powered virtual assistant built using the MERN stack (MongoDB, Express.js, React.js, Node.js). It integrates speech recognition, natural language processing, and text-to-speech capabilities to create an interactive, voice-controlled experience.
![](https://github.com/Manishkannoujiya/AI_Virtual_Assistance/blob/main/Screenshot%202025-08-22%20224133.png)

## Key Features

* Voice Commands & Responses: Uses Web Speech API for real-time speech recognition and speech synthesis.

* AI-Powered Responses: Leverages Gemini/OpenAI API for intelligent, context-aware answers.

* Customizable Assistant: Users can personalize assistant name, voice, and appearance.

* Command Execution: Performs tasks like Google search, weather info, YouTube search, and social media navigation.

* User Authentication & History: Stores user data and command history securely using JWT authentication and MongoDB.

* Responsive UI: Built with React.js and Tailwind CSS for a modern, responsive interface.

## Tech Stack

* Frontend: React.js, Tailwind CSS

* Backend: Node.js, Express.js

* Database: MongoDB

* AI Integration: Gemini/OpenAI API

* Authentication: JWT, Cookies

Speech Features: Web Speech API (SpeechRecognition & SpeechSynthesis)
